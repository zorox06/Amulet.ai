# Breaking Change Guardian

An on-demand P0 demo of the core loop:

`Exa signal -> TypeScript call-site index -> vendor match -> migration fix -> GitHub PR`

## Run the seeded demo

The Stripe demo repository is intentionally checked in so the presentation does not depend on live discovery. Exa is queried when `EXA_API_KEY` is present; if Exa is unavailable, the validated Stripe Sources signal is used and the run reports `live: false`.

```powershell
npm install
npm run build
npm run demo:stripe
```

The output includes the source, confidence, every indexed call site, the matched call site, and the exact old/new line used for the proposed fix. If `GEMINI_API_KEY` is set, the fix is generated by Gemini; otherwise the demo uses the checked-in deterministic migration rule. Set `GEMINI_FIX_MODEL` to a model available to your Gemini project.

## Open a real PR

Configure a GitHub App installation, then set `GITHUB_REPO=owner/repository` and `OPEN_PR=true`. The adapter creates a short-lived installation token, creates a branch from `GITHUB_BASE`, updates the matched TypeScript file through the GitHub Contents API, and opens a PR containing the Exa source link. Without an installation or with `OPEN_PR=false`, it returns a safe `preview://` result and makes no external write.

```powershell
$env:OPEN_PR='true'
$env:GITHUB_REPO='your-org/your-demo-repo'
npm run demo:stripe
```

`POST /api/demo/run` exposes the same flow for a UI: `{ "vendor": "stripe", "openPr": false }`.

## Review dashboard

Run the server with `npm run dev` and open `/review`. The dashboard runs the P0 scan, shows the source/matches/diff, lets a reviewer request a Gemini rewrite, and only creates a PR after **Approve & open PR**. Set `OPEN_PR=true` plus the GitHub settings before approval to permit that write.

## Demo truthfulness

- Seeded: the two known migration scenarios and the local TypeScript repositories.
- Live when configured: Exa search and GitHub branch/file/PR writes.
- Deterministic: AST indexing, matching, migration line generation, and the offline fallback.

P1 CopilotKit review is deliberately not coupled to this P0 path until the core loop is proven.
